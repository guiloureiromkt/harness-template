# saida/ · o que este harness publica

Tudo que outro harness, outra pessoa ou o relatório da empresa precisa ler deste harness vem parar aqui. **Outro harness nunca lê o teu repositório inteiro, só esta pasta.** É isso que impede a Carol do financeiro de virar a Carol do conteúdo.

Regras:
- Um arquivo por saída, nome fixo, sobrescrito a cada rodada (`relatorio-diario.md`, `relatorio-semanal.md`, `criativos/`).
- Todo número carrega a origem (plataforma, data, link) na mesma linha.
- Nada aqui é rascunho: o que está em `saida/` pode ser lido por quem não conhece este harness.
